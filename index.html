Features

⬡

Fully Local

Runs entirely on your machine. Your queries never leave your computer.

⬡

No API Keys

No OpenAI. No Anthropic. No subscriptions. Completely free to run.

⬡

Any Ollama Model

Default is gemma3. Swap to phi3, llama3.2, mistral — whatever fits your hardware.

⬡

Sourced Answers

Every response shows you exactly where the information came from.

Quick Start

1

Install Ollama

Download from ollama.com, then pull a model:

ollama pull gemma3
2

Download Crawl

Grab the Windows executable above and run it — no Python install needed.

3

Ask anything

crawl> what is quantum computing?
